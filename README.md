## Project Overview

This repository documents my Week 2 practical activities as part of the Networkwalks Cybersecurity Internship (Batch B084).

The project focuses on two key phases of penetration testing: footprinting and reconnaissance, followed by network scanning and host discovery.

The practical exercises provided hands-on experience using Kali Linux tools and Zenmap to gather information, examine DNS records, identify website technologies, discover live hosts, and visualize network topology.

## Modules Completed

### W2-PM1: Footprinting with Multiple Kali Linux Tools

This module involved using six Kali Linux tools to perform reconnaissance and gather publicly available information about the assigned domain, `networkwalks.com`.

**Tools Used:**

- WHOIS – Domain registration information.
- WhatWeb – Website technology identification.
- NSLookup – DNS lookup and IP address resolution.
- cURL – HTTP response headers.
- WAFW00F – Web Application Firewall identification.
- DNSRecon – DNS enumeration and record discovery.

### W2-PM5: Network Scanning with Zenmap

This module involved identifying my local network configuration and performing host discovery using Zenmap.

**Practical Activities:**

- Identifying the local IP address and LAN subnet.
- Performing a Ping Scan using Zenmap.
- Discovering active hosts on the local network.
- Identifying IP addresses and MAC addresses.
- Generating and saving a network topology diagram.
